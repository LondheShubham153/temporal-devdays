# Contributing

Thanks for helping. The rules are in [AGENTS.md](AGENTS.md); the short version:

1. Fork the repo, create a branch (`feat/...` or `fix/...`).
2. Keep one exercise or one fix per pull request.
3. Use [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
4. Run `make check` before you open the pull request. It must pass.
5. Add a new exercise by copying an existing pair. Keep code small and beginner friendly.

Do not commit secrets, personal emails or build output.
